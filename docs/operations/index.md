# 运维文档

本分类覆盖从本地启动到生产运行、监控和故障恢复的操作流程。

- [本地开发](./local_development.md)：给出依赖、环境变量、启动、初始化、常用脚本和验证路径。读取时机：首次搭建开发环境、重置数据库或执行本地验证时读取。
- [Docker 安装引导](./docker_installation.md)：通过交互式脚本选择内置或外部 PostgreSQL/Redis，生成生产配置、构建 Compose 镜像并完成首次启动。读取时机：在新服务器自托管安装或生成完整 Docker Compose 部署时读取。
- [部署与运行手册](./deployment_and_runbook.md)：给出部署单元、迁移顺序、健康检查、备份、安全检查和常见故障处置。读取时机：发布、值班、扩容、恢复或排查线上问题时读取。
