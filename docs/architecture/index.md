# 架构文档

本分类说明系统级边界、组件关系和跨模块不变量，不重复单个业务领域的详细规则。

- [系统总览](./system_overview.md)：描述产品边界、运行组件、同步与异步数据流及部署关系。读取时机：接手项目、规划跨应用能力或评估整体影响时读取。
- [后端分层](./backend_layers.md)：规定 Route、Service、Repository、数据库和共享包的职责与依赖方向。读取时机：新增后端功能、拆分模块或审查边界时读取。
- [数据与安全架构](./data_and_security.md)：说明数据分组、多租户 RLS、RBAC、凭证保护、事务和审计。读取时机：修改 schema、权限、数据库上下文、密钥或审计机制时读取。
- [企业级 UI 设计系统](./ui_design_system.md)：定义字体层级、颜色、间距、组件状态、响应式和错误呈现规则。读取时机：新增页面、修改样式、使用 Ant Design 组件或处理前端显示问题时读取。
- [平台管理架构](./platform_administration.md)：定义全局用户、腾讯企业与品牌的资源关系、管理控制面与写入规则。读取时机：修改 `/admin`、平台权限或跨租户管理 API 时读取。
