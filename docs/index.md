# AnswerBit GEO 工程文档

本目录是当前系统设计、领域规则、接口契约、运行手册和架构决策的权威入口。实现事实以当前代码、迁移、测试和配置为依据；`archive/` 仅保留历史背景，不参与当前设计判定。

## 分级目录

- [架构](./architecture/index.md)：系统边界、组件职责、后端分层、数据与安全不变量。读取时机：评估跨模块改动、数据流、技术边界或安全影响时读取。
- [领域](./domains/index.md)：身份权限、余额发布和 GEO 运营的业务规则与状态机。读取时机：修改业务流程、权限、计费、发布或 AnswerBit 能力时读取。
- [接口](./interfaces/index.md)：HTTP 约定、OpenAPI 和腾讯 AnswerBit 集成契约。读取时机：开发或联调 API、处理上游调用和错误语义时读取。
- [运维](./operations/index.md)：本地开发、部署、迁移、健康检查和故障处置。读取时机：搭建环境、发布版本、值班或排障时读取。
- [架构决策](./decisions/index.md)：需要长期保留背景、取舍和后果的 ADR。读取时机：准备改变既有架构取舍或审查设计依据时读取。
- [历史归档](./archive/index.md)：早期需求、设计、计划和审查材料。读取时机：追溯历史背景时读取；不得据此推断当前行为。

## 使用规则

1. 每项仓库任务先读本页，再按“读取时机”进入一个或多个分类目录。
2. 分类目录是该分类文档的唯一规范清单；跨分类关系使用普通链接。
3. 当前设计与历史归档冲突时，以当前状态文档和已验证实现为准。
4. 修改跨模块行为、领域规则、接口、数据模型或运行方式时，同步更新对应正文、目录和代码锚点。
