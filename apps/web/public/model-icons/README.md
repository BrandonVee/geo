# Model icons

AI/LLM brand SVGs in this directory are sourced from
[Lobe Icons](https://github.com/lobehub/lobe-icons), package
`@lobehub/icons-static-svg@1.95.0`, under the MIT license.
The Kimi glyph fill is adapted to its brand blue so it remains visible on the
dashboard's light card background.

`metaso.png` is the public application icon served by the official
`metaso.cn` website.
